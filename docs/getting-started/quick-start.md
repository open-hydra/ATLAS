# Quick Start

This quick start builds a minimal ATLAS case for a 3-D De Laval nozzle with:

- an air phase generated by GPB
- inlet and isothermal-wall boundary conditions generated by BCB
- nozzle initial conditions generated by ICB

## Prerequisites

- ATLAS installed (see [Installation Guide](./installation))
- a working shell setup (`source .setvars.sh` or `./install.sh setvars`)
- a mesh file already available before running BCB and ICB

## Case Layout

Create a fresh case directory and copy in the files needed by this tutorial:

```bash
mkdir nozzle3d-air
cd nozzle3d-air

# mesh required by BCB and ICB
cp <ATLAS_HOME>/test/ICB/IG-nozzle3D/mesh.tec ./

# wall temperature profile required by the isothermal BC
cp <ATLAS_HOME>/test/BCB/IG-xtheta-variable-T/Twall.dat ./
```

At this point the directory should contain at least:

- `mesh.tec`
- `Twall.dat`

## One Combined input.ini

You may keep separate input files for GPB, BCB, and ICB, but ATLAS also supports a single shared `input.ini` containing the sections needed by all tools. This is often the simplest way to manage a case.

Create `input.ini` in the case directory:

```ini
[GPB-Phase1]
mixture-name = air
mixture = {N2: 75.4} {O2: 23.3} {Ar: 1.3}
thermo = NASA9
transport = CEA

[ATLAS-Parameters]
IC-format = vtk-binary

[ICB-Block1]
type = nozzle
p0 = 10.342
T0 = 555.56
nozzle-threshold = 0.0

[BCB-Block1]
face1 = inflow
face2 = extrapolation
face3 = symmetry
face4 = isoth
face5 = symmetry
face6 = symmetry

[inflow]
type = inlet
p0 = 3.0e+5
T0 = 500.0

[isoth]
type = wall
direction = xt
T-file = Twall.dat
```

## Build The Full Case

From the case directory, run:

```bash
# Phase properties first
ATLAS GPB

# Then boundary conditions and initial conditions
ATLAS BCB
ATLAS ICB
```

You can also run the whole sequence in one command when using a combined `input.ini`:

```bash
ATLAS GPB BCB ICB
```

!!! warning 
    The order matters:

    - **GPB can always be run independently** because it only needs the phase definition.
    - **BCB and ICB require a mesh file** to already exist in the case directory.
    - **GPB output is required before invoking BCB and ICB** for a full case setup, because the downstream tools rely on the generated phase/property data.

## What Each Step Produces

### GPB

GPB reads `[GPB-Phase1]` and writes the phase-property files needed by the solver workflow.

These files are written under `fromATLAStoSolver/`.

### BCB

BCB reads the mesh plus the `[BCB-Block1]`, `[inflow]`, and `[isoth]` sections and generates the boundary-condition block files.

In this example:

- `face1` is an inlet
- `face4` is an isothermal wall using `Twall.dat`
- the remaining faces are symmetry or extrapolation boundaries

### ICB

ICB reads the nozzle initialization section and writes the initial field for the mesh.

The `type = nozzle` block sets up a De Laval nozzle initialization using the stagnation conditions `p0` and `T0`.

## Check Results

After the full sequence completes, inspect the case directory:

```bash
ls -la
ls -la fromATLAStoSolver
```
