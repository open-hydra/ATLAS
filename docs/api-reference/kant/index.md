## Package Structure

| Module | Description |
|--------|-------------|
| `KAnT.__main__` | CLI entry point |
| `KAnT.config` | INI configuration parsing |
| `KAnT.data` | Thermodynamic / kinetics data helpers |
| `KAnT.output` | Result writers |
| `KAnT.simulations.counterflow` | Counterflow flame driver |
| `KAnT.simulations.equilibrium` | Chemical equilibrium driver |
| `KAnT.simulations.ignition_delay` | Ignition delay driver |
| `KAnT.simulations.time_evolution` | Time-evolution reactor driver |
| `KAnT.utils` | Shared utilities |
