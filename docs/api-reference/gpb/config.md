# GPB Config

Source: `src/hydra-tools/GPB/config.py`

## Constants

| Name | Value | Description |
|------|-------|-------------|
| `ATLASDIR` | `$ATLASDIR` env var | Root directory of the ATLAS installation |
| `OUTPATH` | `"fromATLAStoSolver/"` | Output directory for binary property files |
| `HG_FACTOR` | `1.0e+5` | Pressure scaling factor for heavy-gas phases |
| `HG_SUBSTRING` | `"-HG"` | Suffix appended to heavy-gas phase output filenames |
| `CEA_TRANS_FILE` | `$ATLASDIR/database/transport/CEApolynomials.yaml` | CEA transport polynomial database |
