# GPB Output Files

## Output Directory

GPB writes generated files to:

```text
fromATLAStoSolver/
```

## Naming Convention

For each GPB section, the output filename prefix is built from the section `name` key:

- if `name = air`, prefix is `air-`
- if `name` is omitted, prefix is empty

So files are emitted as:

```text
fromATLAStoSolver/<prefix><suffix>
```

where `<suffix>` depends on the phase/type (see below).

## File Format

GPB currently writes plain-text files (Tecplot-style `.dat` plus descriptor `.txt`).

## Ideal-Gas Outputs

Generated by `src/hydra-tools/GPB/ideal_gas/io.py`.

### `<prefix>phase.txt`

- first line: `ideal-gas phase`
- then one line per species:

```text
<species_name> <molecular_weight>
```

### `<prefix>thermo.dat`

Tecplot point format with one zone per species.

Variables:

1. `Temperature`
2. `Cp`
3. `Enthalpy`
4. `Entropy`
5. `dCp`

Temperature grid is integer-spaced from `Tmin` to `Tmax` (inclusive).

### `<prefix>transport.dat`

Tecplot point format with one zone per species.

Variables:

1. `Temperature`
2. `Viscosity`
3. `Conductivity`

### `<prefix>composition.txt` (reactive/equilibrium data)

Species composition file for equilibrium simulations.

### Chemistry (when reactions are processed)

Finite-rate chemistry files for reactive simulations, if reactions are processed:

- `<prefix>chemistry-info.txt`
- `<prefix>chemistry-Arrhenius.dat`
- `<prefix>chemistry-Troe.dat`
- `<prefix>chemistry-Lindemann.dat`

The `chemistry-info.txt` file contains a summary of the reactions and their parameters, while the `chemistry-*.dat` files are Tecplot point datasets with one zone per reaction and `Temperature` as the first variable and forward/backward rates.

## Condensed / Solid Outputs

Generated by `src/hydra-tools/GPB/condensed/io.py`.

### `<prefix>phase.txt`

- first line is `condensed-dispersed phase` for condensed-dispersed mode, or `solid phase` for solid mode
- then one line per material:

```text
<material_name> <group_id>
```

### `<prefix>properties.dat`

Tecplot point format with one zone per species/material and an integer-spaced temperature grid from `Tmin` to `Tmax` (inclusive).

If type contains `dispersed`, variables are:

1. `Temperature`
2. `Cp`
3. `Density`
4. `Enthalpy`

Otherwise variables are:

1. `Temperature`
2. `Cp`
3. `Density`
4. `Conductivity`
5. `Energy`

## Real-Fluid Outputs

Generated by `src/hydra-tools/GPB/real_fluid/io.py`.

### `<prefix>phase.txt`

Two lines:

1. `real-gas phase`
2. fluid name

### `<prefix>thermo.dat`

Tecplot block format with zone dimensions `I=NP`, `J=NH`.

Variables:

1. `Pressure`
2. `Enthalpy`
3. `Density`
4. `Temperature`
5. `dRho/dT`
6. `dRho/dh`
7. `Cp`
8. `Entropy`
9. `dRho/dp`
10. `SoundSpeed`

### `<prefix>transport.dat`

Tecplot nodal dataset for the same `NP x NH` table.

Variables:

1. `Pressure`
2. `Enthalpy`
3. `Viscosity`
4. `Conductivity`

## Examples

### Example 1: ideal-gas section with `name = air`

If your INI section contains:

```ini
[GPB-Phase1]
type = ideal-gas
name = air
```

GPB writes files such as:

- `fromATLAStoSolver/air-phase.txt`
- `fromATLAStoSolver/air-thermo.dat`
- `fromATLAStoSolver/air-transport.dat`

Example `air-phase.txt`:

```text
ideal-gas phase
N2 28.013400
O2 31.998800
```

Example first lines of `air-thermo.dat`:

```text
TITLE = "Mass Thermodynamic Properties"
VARIABLES = "Temperature", "Cp", "Enthalpy", "Entropy", "dCp"
ZONE T="N2"
I=5000, F=POINT
```

### Example 2: condensed-dispersed section with `name = alumina`

If your INI section contains:

```ini
[GPB-Phase2]
type = condensed-dispersed
name = alumina
```

GPB writes files such as:

- `fromATLAStoSolver/alumina-phase.txt`
- `fromATLAStoSolver/alumina-properties.dat`

Example `alumina-phase.txt`:

```text
condensed-dispersed phase
Al2O3 1
```

Example first lines of `alumina-properties.dat`:

```text
TITLE = "Mass Thermodynamic Properties"
VARIABLES = "Temperature", "Cp", "Density", "Enthalpy"
ZONE T="Al2O3"
I=3000, F=POINT
```

### Example 3: real-fluid section with `name = n2rf`

If your INI section contains:

```ini
[GPB-Phase3]
type = real-fluid
name = n2rf
fluid = Nitrogen
NP = 200
NH = 200
```

GPB writes files such as:

- `fromATLAStoSolver/n2rf-phase.txt`
- `fromATLAStoSolver/n2rf-thermo.dat`
- `fromATLAStoSolver/n2rf-transport.dat`

Example `n2rf-phase.txt`:

```text
real-gas phase
Nitrogen
```

Example first lines of `n2rf-thermo.dat`:

```text
TITLE = "Mass Thermodynamic Properties"
VARIABLES = "Pressure", "Enthalpy", "Density", "Temperature", "dRho/dT", "dRho/dh", "Cp", "Entropy", "dRho/dp", "SoundSpeed"
ZONE T=real-gas, I=200, J=200, K=1, DATAPACKING=BLOCK, VARLOCATION=([1-10]=NODAL)
```

### Example 4: omitted `name`

If `name` is omitted, filenames do not get a prefix. For an ideal-gas section this means files are:

- `fromATLAStoSolver/phase.txt`
- `fromATLAStoSolver/thermo.dat`
- `fromATLAStoSolver/transport.dat`
