# Theory

Background material on the physical models and numerical methods implemented in ATLAS and Hydra.

## Contents

| Page | Description |
|------|-------------|
| [Thermodynamics](./thermodynamics) | Equations of state, caloric model, enthalpy/entropy relations |
| [Transport Properties](./transport) | Viscosity and thermal conductivity models (Sutherland, CEA, Cantera) |
| [Equations of State](./equations-of-state) | Ideal gas, Redlich–Kwong, Peng–Robinson, CoolProp lookup tables |
| [Chemical Equilibrium](./chemical-equilibrium) | Cantera and CEA equilibrium computations used by GPB |

## Scope

This guide covers theory directly relevant to the ATLAS pre-processing step: how property tables are generated and what assumptions underlie them. For the Hydra solver numerics (flux schemes, time integration, turbulence models) see the Hydra documentation.
