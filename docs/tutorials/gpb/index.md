| [Condensed phase](./condensed.md) | `CP-Tvar-dispersed` | Validate temperature-dependent condensed/dispersed phase-property tables. |
| [Solid phase](./solid.md) | `SP-Tvar` | Validate temperature-dependent solid-material property tables. |
| [Real fluid — CO₂](./real-fluid.md) | `RF-co2` | Validate real-fluid property-table generation for CO2 workflows. |
