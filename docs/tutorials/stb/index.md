# Source Terms (STB)

STB writes the volumetric sources of the energy equation and the area tables of Q2D. Each tutorial runs a test case
of `test/STB/`.

| Tutorial | Case | You learn |
|----------|------|-----------|
| [A Volumetric Heat Source](heat-source.md) | `uniform`, `x-variable` | a uniform source and a profile |
| [Area Tables for Q2D](area-tables.md) | `area-any-order` | the cross-section area of a quasi-2-D channel |
