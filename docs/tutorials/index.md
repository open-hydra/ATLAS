# Tutorials

Step-by-step guides based on reference cases in `test/`.
Each tutorial maps to one or more regression cases and explains the test objective.

## GPB Tutorials

| Tutorial | Description |
|----------|-------------|
| [Fixed-gas mixture](./gpb/fixed-gas.md) | Validate ideal-gas setup from fixed thermodynamic and transport constants |
| [Cantera ideal-gas](./gpb/cantera-ideal-gas.md) | Validate Cantera-based ideal-gas property generation |
| [Cantera equilibrium](./gpb/cantera-equilibrium.md) | Validate equilibrium composition and properties computed with Cantera |
| [CEA reactive](./gpb/cea-reactive.md) | Validate reactive mixture setup from CEA input data |
| [Heavy-gas mixture](./gpb/heavy-gas.md) | Validate heavy-gas mixture workflows with gas/condensed coupling |
| [Condensed phase](./gpb/condensed.md) | Validate temperature-dependent condensed/dispersed phase tables |
| [Solid phase](./gpb/solid.md) | Validate solid-material property table generation |
| [Real fluid (CoolProp)](./gpb/real-fluid.md) | Validate real-fluid table generation (e.g., near-critical $\text{CO}_2$) |
