# Transport Databases

ATLAS provides three transport property databases. Two are static YAML files (CEA polynomial curve fits and Lennard-Jones kinetic theory), and one is a Python module.

| Name | Model | Phase | Source |
|---|---|---|---|
| CEA | CEA polynomials | all | NASA Glenn Research Center |
| Lennard-Jones | Kinetic theory | all | Varying |
| Custom | Hard-coded | all | Varying |
