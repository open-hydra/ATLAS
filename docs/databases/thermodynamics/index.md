# Thermodynamics Databases

ATLAS bundles four thermodynamic database files, covering ideal-gas species from cryogenic to plasma temperatures, as well as real-fluid equations of state for high-pressure propellants.


| Name | Format | Phase | Temperature range | Source |
|---|---|---|---|---|
| NASA | NASA9 polynomials | all | 200 – 20 000 K | NASA Glenn Research Center |
| Burcat | NASA7 polynomials | all | 200 – 6000 K | Burcat / Goos / Ruscic (ATcT) |
| Real-fluid EOS | Analytical | real-fluid | 273 – 1273 K | Peng–Robinson, Redlich–Kwong |
| CoolProp | External | real-fluid | 273 – 1273 K | CoolProp database for 100+ fluids |
| Custom | Python | all | 300 – 3000 K | Varying |
