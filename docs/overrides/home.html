Up and running in minutes

Install ATLAS, build the toolchain, and generate your first pre-processing artifacts for Hydra.

Installation guide → Quick start
terminal 
# Clone and build
$ git clone https://github.com/open-hydra/ATLAS.git
$ cd ATLAS && ./install.sh

# Generate phase tables (example)
$ ATLAS GPB --input input.ini
