Everything needed before solver runtime

ATLAS prepares physically consistent inputs and tables for Hydra simulations

GPB

General Phase Builder for ideal gas, condensed, solid, and real-fluid phases with transport and thermo tables.

BCB

Boundary Condition Builder that writes boundary blocks for inlets, outlets, walls, and advanced user-defined setups.

ICB

Initial Condition Builder with support for direct specification, interpolation strategies, and restart-friendly workflows.

STB

Setup Tool Builder for geometry and area-law preprocessing used by Hydra initialization and runtime setup.

KAnT

Kinetics and Thermodynamics post-processing utility for 0-D studies and validation-ready thermo-chemical analysis.

Multi-language Stack

Fortran tools and Python packages share a unified CMake workflow, making integration and CI straightforward.

Up and running in minutes

Install ATLAS, build the toolchain, and generate your first pre-processing artifacts for Hydra.

Installation guide → Quick start
terminal 
# Clone and build
$ git clone https://github.com/open-hydra/ATLAS.git
$ cd ATLAS && ./install.sh

# Generate phase tables (example)
$ python -m GPB --input-file gpb.ini
