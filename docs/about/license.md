## License Compatibility

### Compatible Licenses

GPL-3.0 code can generally be combined with permissive licenses and some copyleft licenses. Common examples include:

- **GPL v3.0** - Same license ✅
- **LGPL v3.0** - Compatible under GPLv3 terms ✅
- **Apache 2.0** - Compatible with notice requirements ✅
- **MIT** - Can incorporate MIT code ✅
- **BSD (2/3-clause)** - Can incorporate BSD-licensed code ✅

AGPL v3.0 has special rules. Combined works are typically conveyed under AGPL v3.0 terms.

### Incompatible Licenses

GPL-3.0 is **not compatible** with:

- **GPL v2.0-only** - Not compatible without an "or later" upgrade path ❌
- **Proprietary licenses** - Closed source ❌

!!! warning "License Compatibility"
    When combining ATLAS with other software, ensure all licenses are compatible.
